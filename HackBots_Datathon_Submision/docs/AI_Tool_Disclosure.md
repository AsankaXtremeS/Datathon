# AI Tool Disclosure

**Team HackBots · Tech-Triathlon 2026 Datathon**

**Tool used:** Claude Code (Anthropic), an AI coding assistant in VS Code.

**AI-assisted:** writing and debugging code, running experiments, suggesting ideas, and drafting documentation.

**Done by the team:** the problem framing and overall logic, the choice of approach for each task, deciding which suggestions to keep or reject, running and reviewing the notebooks, and checking every result.

**How we used it:** the team worked task by task, gave the instructions and reviewed each output before moving on. All reported numbers come from executed notebook cells. The submitted models were trained from scratch with scikit-learn. We used no pre-trained models, no proprietary model APIs and no AutoML tools.
